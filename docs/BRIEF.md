# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：短肠综合征（肠衰竭）患者及家属照护者；含肠切除术后恢复期、长期肠外营养依赖、过渡至代偿期/肠康复治疗的患者；患者组织志愿者协作使用

场景：肠切除术后档案（剩余肠段/造口/吻合方式，医生原话留痕）；肠外肠内营养按次登记（PN量·时长·途径·输液日历）；体重出入量与营养状态趋势；电解质与维生素微量元素周期化验（方法分组不合并）；中心静脉导管并发症随访；PNALD/肾功能/骨病/胆石筛查节奏；脱水与急性症状行动计划（医生确认原话）；慢特病医保与肠内营养特医食品资源

核心流程：
1. 选择本机资料目录并导入出院小结/手术记录/化验单
2. 核对候选信息，建立术后档案与营养支持方案登记
3. 按日登记输液与出入量，查看营养状态趋势
4. 整理化验随访分组趋势与并发症筛查节奏
5. 生成复诊准备材料与就医问题清单

完成结果：得到来源可追溯、可核对的个人肠衰竭档案：营养支持登记与日历、营养状态趋势、化验随访分组趋势、导管与并发症筛查记录、复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
