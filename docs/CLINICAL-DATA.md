# CLINICAL-DATA · 小养宝 NutriPal（短肠综合征）

版本：v0.1（M0 骨架；M1 十主题核数并落单一证据台账）。

## 内容边界声明

指南与文献只定「内容边界」（该监测什么、随访节奏一般是什么），不转成自测、不转成选治疗建议。未过临床审核的阈值与求助短语一律【待核】占位。中国适应证只认中国官方来源（NMPA 等）。

## M1 十主题核数清单（骨架）

1. SBS 定义与肠衰竭分型（指南 #73 官方文本）
2. 剩余肠段长度与结局关系（边界知识，只展示医生原文）
3. PN 处方要素与记录维度（量/时长/途径/周期）
4. 电解质与微量元素监测项目集（镁/钾/磷/锌/铜/硒/B12/VD/ADEK）
5. PNALD 定义、监测手段（肝功能项集）与随访节奏
6. 中心静脉导管并发症分类（CRBSI/堵管/移位/血栓）与登记维度
7. SIBO/胆石/骨病/肾功能筛查项
8. 肠康复治疗与 GLP-2 类药物（只列医生原文与日期，不判定；中国获批状态查 NMPA）
9. 特医食品与肠内营养制剂（NMPA 注册口径）
10. 医保支付与报销路径（地方差异如实标注「未核实到全国口径」）

## 数据实体边界（M3 schema 前置）

- 事实层实体：档案（档案/术后事实）、营养支持方案（版本链）、输液登记（按次）、出入量/体重（按日）、化验（报告→指标值，含方法/单位/机构）、事件（用药/就诊/检查/并发症）、筛查项、文档原件索引。
- 禁止入库：诊断、risk_level、activity_score、任何派生判定（Q38）；派生值读时算（Q39）。
- 数据层基线：ORDER BY rowid、显式 null、in_use、分节 *_title、分类不进趋势（Q37）。

## 来源登记规则

原件 / 题录 / 二次来源 / 未取得 分开标；失败 URL 与待决问题留痕；版本与获取时点记录。单一证据台账落在 research/ 目录（M1）。
