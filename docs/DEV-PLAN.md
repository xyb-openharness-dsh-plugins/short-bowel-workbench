## 1. 病种与领取理由

- 病种：短肠综合征（Short Bowel Syndrome，SBS），《86 个罕见病病种诊疗指南（2025 年版）》罕见病 #73（p428），R2 非肿瘤慢性病型，T2。
- 领取理由（对照「优先 T0/T1、随访天然结构化、与已有仓差异化明显」）：
  1. T0/T1 未认领名额已于 2026-10-26 后被认领完毕（BACKLOG 全表逐一核对 + org 仓列表 + 全部开放 issue 比对）；剩余未认领池中 SBS 是差异化最强、随访结构化最天然的候选之一。
  2. 随访天然结构化：肠外营养（PN）按次登记（量/时长/途径）、体重与出入量、电解质与维生素微量元素周期化验、中心静脉导管并发症、PNALD/肾功能/骨病/胆石筛查——全部是可结构化的条目型数据。
  3. 差异化明显：家族现有仓为肿瘤线（27 个）与血管炎/胆汁淤积/血液罕见病；无任何仓覆盖「肠衰竭—营养支持」维度。SBS 核心节律是「输液日历 + 营养状态」，与复发型（心包炎）和炎症型（血管炎）的组织方式都不同。
- 未选候选与原因：巨细胞动脉炎（T2，与大动脉炎仓同属大血管炎，重名率风险高）；小肠腺癌（T2，与消化道肿瘤族重名）；原发性免疫缺陷病（T1 🔥，但 R3 儿童线认领主体必须是患儿家长，无人值守代理不满足开工条件，规则上不开工）。

## 4. M4 裁剪决策（预先声明）

SBS 为非肿瘤病种，无 NCCN 试验目录对应。M4 的「四在线通道试验抓取」改为：以 ClinicalTrials.gov API v2 公开接口检索「short bowel syndrome」干预性试验快照（只做线索台账，不判读），并叠加《86 个罕见病病种诊疗指南（2025 年版）》#73 的官方文本作为内容边界源。若服务不可用，如实记 FAILED，不写零结果。禁匹配指数与判读列（35 号）。
