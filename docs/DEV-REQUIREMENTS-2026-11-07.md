## 一、患者视角红线（本项目内一票否决）

1. 功能按患者关心的信息维度组织：营养支持怎么记、化验怎么比、导管怎么防感染、复诊问什么。医生任务（如分级判定、治疗方案生成）冒充患者功能即否决。
2. 每条功能线挂患者原话；本项目 0 患者访谈，如实标注「0 访谈」，场景改写句不冒充引语。
3. 0 临床审核：所有阈值、参考范围、求助短语一律【待核】占位，不冒充已审。

## 二、家族基线（开发检查点清单 1.1，全条适用）

令牌先于组件；正文 15px/行高 1.65–1.68/tabular-nums；三段外壳；按钮 ≥42px；统一类名词汇；口径文案同屏（「仅回顾，不解读」「解读归医生」「不同方法不合并」）；空态带下一步按钮；私密三出口共用过滤函数并显示「N 条中私密 M 条」；AI 输出永远候选/预览；无障碍基线；断点 1180/900/600。

## 三、SBS 特有硬约束

1. 营养支持按次登记是事实层主实体：PN 量（ml 或 kcal，显式单位）、时长、途径（中心静脉导管类型）、开始结束时间；不派生「达标率」等判定列。
2. 输液日历以「输液日 / 非输液日」表达节律，不用疗程编号。
3. 化验分组按「指标 + 方法 + 单位 + 机构」可比组连线；跨方法不连线不做差（MT06）。
4. 导管并发症与筛查项（PNALD、肾功能、骨病、胆石、SIBO）只做登记与节奏提醒，不做判定；发热/CRP 阈值提示一律【待核】。
5. 脱水/急性症状「行动计划」只用患者与医生已确认原话（「若出现 X 联系 Y」），无原话时给「带问题问医生」出口，不生成医疗建议。
6. 全站禁词（非肿瘤 1.3 表 + SBS 扩充）：病期、线序、疗效、预后、生存期、MRD、缓解期（SBS 无缓解语义；用「稳定期/恢复期」且仅复述医生原文时保留）、自动判定类词（诊断、分级、评分自动输出）。

## 四、隐私

- 演示数据全部标注「合成示例 · 仅演示 · 未连接宿主」（Q13）。
