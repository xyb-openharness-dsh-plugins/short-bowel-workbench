# DIFF-MATRIX · 小养宝 NutriPal（短肠综合征）

版本：v0.1（M0 骨架；M1 按调研全量展开并实测重名率 ≤70%）。
目的：防「换名复用」——每个功能必须有 SBS 特有语义，禁止从既有仓复制肿瘤/炎症/复发语义。

## 二、差异化矩阵（≥3 条，场景/功能/怎么验）

1. 场景：PN 依赖者天天记「输了多少、输多久、什么通路」，漏记后出入量算不平 → 功能：营养支持按次登记 + 输液日历节奏带 → 验收：A/B 两套合成档案切换后日历与登记整页联动不串档；全站无 D+N/病期/线序禁词（check 断言）。
2. 场景：电解质与微量元素化验单散落各机构，不同方法不可比 → 功能：一图秀按「指标+方法+单位+机构」分组连线，「不同方法不合并」同屏 → 验收：MT03 两页目录一致实测、MT06 跨方法断线实测。
3. 场景：中心静脉导管是生命线也是感染源 → 功能：导管事件登记 + 并发症筛查节奏清单 + 时间线泳道 → 验收：无自动判定（阈值【待核】），事件可回查到原始来源。
4. 场景：PN 长期使用者担心肝肾功能与骨健康 → 功能：并发症筛查（PNALD/肾功能/骨病/胆石）随访清单 → 验收：筛查项只登记与提醒，无风险评分列（schema 无判定列，G3 断言）。

## 三、禁词表（SBS 版，check 断言用）

肿瘤语义：分期、病期、线序、一线、二线、疗效应答、CR/PR/SD/PD、生存期、复发带缓解语义、MRD、肿瘤标志物。
SBS 特别禁用：缓解期（SBS 用「稳定期」且仅医生原文引用）、危险度分层、fit 评分。
