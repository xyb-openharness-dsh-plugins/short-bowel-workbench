## 一、重名率实测

- 一级导航：SBS 9 项中与家族逐字重名 3 项（看板、营养支持、病情一图秀）→ **33.3% ≤ 70%** ✓
- 统计口径：只比对一级名逐字相同；「生活与心理」vs「心理与家庭」、「复诊准备」vs「资料与复诊」为命名不同的变体，不计重名。
- 病种语义重名：0 —— 肿瘤分期/线序/疗效应答/标志物口径在 SBS 全部禁用（禁词表 §三，check 断言）。

## 二、一级功能 × 家族仓差异矩阵

| SBS 一级 | 最接近家族结构 | 结构复用 | SBS 语义（不可替换项） |
| --- | --- | --- | --- |
| 看板 | BRE dashboard（hero/状态卡/task-entry） | stage-card 结构换成「术后第 N 天/距手术 N 天」 | 输液日历打点、本月输液天数、待办筛查 |
| 术后与档案 | BRE records 资料库 | 表列 `材料名称/日期/类型/整理状态/操作` 结构 | 剩余肠段/造口/吻合方式，医生原话版本链，无分期 |
| 营养支持 | BRE nutrition（进食与体重） | Tab 结构 | **PN 按次登记+输液日历节奏带**：量/时长/途径/日；出入量；方案版本链。肿瘤营养线无此维度 |
| 化验随访 | BRE/AML 一图秀指标体系 | 方法分组连线、口径同屏 | 电解质/微量元素项目集、吸收不良语境、「不同方法不合并」 |
| 病情一图秀 | AML 泳道（LANES 机制） | 事件泳道结构（输液/并发症/调药三类道） | 无疗程菱形节点（家族 1.3 禁表）；输液日/非输液日带 |
| 导管与并发症 | 无近亲 | AML 时间线结构 | 中心静脉导管档案、CRBSI/堵管/移位、PNALD/肾/骨/胆石筛查节奏，全部登记不判定 |
| 生活与心理 | AML #mind/mind-burden | feelRow 双主体+私密切换、只记事实 notice | 输液节律对出行/工作/社交的影响，不做评分 |
| 复诊准备 | BRE care 就诊准备 | 问题清单+最近报告表结构 | 摘要经私密三出口过滤 |
| 资源与医保 | FSHD 资源线结构 | 资源卡+来源标注 | 特医食品 NMPA 注册口径、肠外营养报销 |

## 三、差异化矩阵（场景/功能/怎么验，对 Issue #65 承诺逐条落实）

1. PN 按次登记与输液日历：A/B 档案切换整页联动不串档（Q9–Q10）；全站禁词 check=0。
2. 化验方法分组不合并：MT03 两页目录一致实测；MT06 跨方法断线实测。
3. 导管事件与筛查节奏：无自动判定（schema 无判定列 G3）；事件回查原始来源。
4. 并发症筛查（PNALD/肾/骨/胆石）：只登记与提醒，阈值【待核】占位（全站 grep【待核】可见）。

## 四、禁词表（check 断言用，SBS 版）

分期、病期、线序、一线、二线、疗效应答、CR/PR/SD/PD、生存期、MRD、肿瘤标志物、危险度分层、fit 评分、缓解期（SBS 用「稳定期」，仅医生原文引用可保留）。
