## 一、定稿导航（一级 9 + 二级 24，全部 SBS 语义）

一级 PAGES（key / 名称 / 眉题副题）：

| key | 名称 | 副题 | 重名判定（vs 家族逐字名） |
| --- | --- | --- | --- |
| home | 看板 | 今天，先把眼前的记录补齐。 | 重名（家族通用词） |
| archive | 术后与档案 | 手术事实与出院小结，医生原话照抄。 | 独有 |
| nutrition | 营养支持 | 输了什么、输多久，一条条记清楚。 | 重名（BRE 营养支持，语义已替换） |
| labs | 化验随访 | 不同方法不合并，只和可比的比。 | 独有 |
| onechart | 病情一图秀 | 趋势归趋势，事件归事件。 | 重名（家族通用词） |
| complications | 导管与并发症 | 生命线也是要盯紧的线。 | 独有 |
| life | 生活与心理 | 输液节律之外的生活，只记事实。 | 独有（AML「心理与家庭」变体，命名不同） |
| visits | 复诊准备 | 带着清单去，带着答案回。 | 独有（AML「资料与复诊」命名不同） |
| resources | 资源与医保 | 能报销什么、去哪找组织。 | 独有 |

二级 SUBPAGES：
- home: `概览 / 最近变化`
- archive: `手术事实 / 出院小结 / 档案汇总`
- nutrition: `输液日历 / 按次登记 / 方案版本 / 出入量`
- labs: `报告列表 / 核对 / 指标目录`
- onechart: `指标趋势 / 事件泳道`
- complications: `导管档案 / 事件时间线 / 筛查节奏`
- life: `生活影响 / 当下感受 / 支持资源`
- visits: `问题清单 / 最近报告 / 就诊记录`
- resources: `特医食品 / 报销与政策 / 病友组织`

重名率实测（一级）：重名 3 / 总 9 = **33.3% ≤ 70%** ✓（统计口径：与 BRE v0.4 或 AML v0.2 一级名逐字相同算重名；变体与独有名不算）。

## 二、IP 交互路径（13 条，每条：入口名=渲染文案=key 逐字一致 → 步骤 → 可观察产物 → 回首页）

| IP | 路径 | 产物 | 回首页 |
| --- | --- | --- | --- |
| IP-01 | 看板→「+ 录一次输液」→nutrition/register 保存 | 登记表 +1、日历当日打点 | ✓ |
| IP-02 | 看板→「看本月输液日历」→nutrition/calendar | 日历打点数=登记条数（断言） | ✓ |
| IP-03 | 看板→「补体重」→nutrition/balance 数字键盘录入 | 趋势点 +1 | ✓ |
| IP-04 | archive/手术事实→「+ 录手术事实」→表单 ≤6 字段保存为医生原文版本 | 档案汇总出现该版本 | ✓ |
| IP-05 | labs/报告列表→「导入化验单」→candidate 核对→勾选入档 | 指标目录 +N、拒收零副作用 | ✓ |
| IP-06 | onechart/指标趋势→选指标+切时间窗 | 曲线重绘、空窗口有空态文案 | ✓ |
| IP-07 | onechart/事件泳道→点事件点 | 详情打开（原始来源），焦点恢复 | ✓ |
| IP-08 | complications/导管档案→「+ 导管事件」登记 | 时间线 +1 | ✓ |
| IP-09 | complications/筛查节奏→勾选已完成筛查 | 下次筛查日期更新 | ✓ |
| IP-10 | life/生活影响→「+ 记一条」双主体选择 | 列表 +1，私密标记可切换 | ✓ |
| IP-11 | visits/问题清单→勾选问题→「生成复诊摘要」 | 摘要预览（私密三出口过滤）+ 可打印 | ✓ |
| IP-12 | resources/病友组织→打开资源卡外链 | 新开来源页 | ✓ |
| IP-13 | 顶栏「?」→疾病概要四段浮层 | P1–P9 全断言 | ✓ |
