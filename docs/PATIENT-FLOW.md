# PATIENT-FLOW · 小养宝 NutriPal（短肠综合征）

版本：v0.1（M0 骨架；M1 经调研补全并做 IP 覆盖断言）。
红线：以下流程均按患者关心的信息维度组织；0 患者访谈，本文所有「患者关心」均为改写推断，不冒充引语。

## 主流程（首次使用）

1. **建立术后档案**：录入出院小结/手术记录关键事实（手术日期、切除范围、剩余肠段长度、造口有无、吻合方式）——全部条目由用户手工录入或从导入文档核对候选，AI 只给候选不代写。未知值显式「未知」，不猜。
2. **登记营养支持方案**：当前 PN 处方要素（每日量、输注时长、途径、添加成分）按次登记；方案变更 = 新版本，不改旧记录。
3. **日常记录**：输液日历打点（输液日/非输液日）、出入量、体重；数字用数字键盘组件录入。
4. **化验归档**：电解质/微量元素/肝肾功能化验单导入 → 指标候选核对入档 → 按可比组看趋势。
5. **随访准备**：复诊前生成「和 AI 讨论」问题清单 + 最近化验摘要（私密三出口过滤），打印或带走。

## 空态与降级

- 新档案零记录：每页给下一步按钮（如「录入第一次输液」），不写「暂无数据」完事（Q 系列硬要求）。
- 缺原件：指标卡写「未取得原件，据二次来源」。
- A/B 两套合成档案覆盖：零条/单条/多条/缺字段/未知日期/私密项/无原件（Q11）。
