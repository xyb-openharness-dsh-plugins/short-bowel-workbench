# SCENARIOS · 小养宝 NutriPal（短肠综合征）

版本：v0.1（M0 骨架；M1 全量场景化并做双向映射）。

**证据声明：本项目 0 患者访谈（截至 2026-11-07）。** 以下场景来自公开罕见病指南文本与病种常识的改写推断，全部标注为推断；无一手引语，改写句不冒充引语。M1 调研将按证据分层（一手/二次/未取得）登记来源。

## S1 · 日常营养节律（核心场景）

- 谁：PN 依赖患者或协助记账的家属。
- 输入：每天是否输液、PN 量与时长、出入量、体重。
- 动作：日历打点 + 按次登记 + 语音/手动补录。
- 输出：输液日历、本月输液天数、营养支持登记表、可导出摘要。
- 完成可观察：日历出现当日打点，登记表 +1 条，趋势图含新点。
- 验收：三态录入按钮（保存并继续/保存并关闭/取消）；连续录入不丢焦点。

## S2 · 化验归档与趋势

- 输入：化验单照片/PDF（导入）或手工录入。
- 动作：候选核对（IP9 双通道同事实层）→ 入档。
- 输出：指标卡 + 一图秀分组趋势。
- 完成可观察：核对后指标页与一图秀同值（MT10）。

## S3 · 导管与并发症随访

- 输入：导管类型/置管日期、事件（感染/堵管/移位）、筛查结果。
- 输出：并发症时间线、筛查节奏清单（下次该查什么）。
- 红线：只登记与提醒；阈值/判读【待核】；无风险评分。

## S4 · 复诊准备

- 输入：近三个月记录。
- 输出：复诊问题清单（用户勾选生成）、化验摘要（私密过滤后）、医生原话回查。
- 红线：问题清单是用户选择的结果，不代生成医疗问题；AI 只协助措辞。

## S5 · 生活与资源（aml #mind 结构移植）

- 输入：出行/工作/社交受输液节律影响的自评记录；特医食品与报销信息。
- 输出：生活影响记录线 + 资源卡（来源标注）。
- 红线：不拍评级，只记录自述与医生确认事实。
