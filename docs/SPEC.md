# 项目规格 · 小养宝 NutriPal 短肠综合征工作台

版本：v1.0-G1（2026-11-07，M1 定稿，签认对象）· 0 患者访谈、0 临床审核。

## 问题、用户与最小闭环

- 问题：短肠综合征患者的日常被营养支持节律、周期化验、导管并发症三件事切分，记录散落在聊天记录、纸质单与记忆里，复诊时拼不出完整事实。
- 用户：成人 SBS 患者本人（主）+ 家属协助记账（次）；0 访谈，全部为推断假设。
- 最小闭环：录入/导入 → 核对候选 → 入档 → 看趋势与节奏 → 带着清单复诊。输入是记录动作，输出是可核对的个人病程档案。
- 失败恢复：核对拒收零副作用（IP5）；更正=新增版本（IP8）。
- 成功标准：患者复诊时能在 5 分钟内带出「最近输液、化验、事件」摘要，且每条可回查来源。

## 方案与 ADR（草案）

- A1 布局：business-first 主区 + 右侧 AI 面板（家族统一形态），理由：记录类任务需要常驻大主区；备选「独立全屏应用」被否——与宿主工作台形态冲突。
- A2 数据：本机 SQLite，事实层单版本链；备选「云同步」被否——隐私红线与宿主本机优先原则。
- A3 非肿瘤裁剪：无试验匹配线，M4 改试验线索台账 + 指南边界（DEV-PLAN §4）。
